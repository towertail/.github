# Security policy

## Supported versions

We fix security issues only in the latest release of each component.
Update to the latest release before you report an issue.

| Component | Supported version |
| --- | --- |
| Towertail apps and server | Latest release |
| Sampler | Latest release |

## Report a vulnerability

Do not open a public issue, discussion, or pull request for a security issue.

Use GitHub private vulnerability reporting:

1. Go to the **Security** tab of the affected repository, for example [towertail/towertail](https://github.com/towertail/towertail/security) or [towertail/sampler](https://github.com/towertail/sampler/security).
2. Click **Report a vulnerability**.
3. Give the affected version, the steps to reproduce the issue, and the possible effect.

## What to expect

- We reply to your report in 7 days.
- We tell you when we have a fix and when we release it.
- We give you credit in the advisory, if you agree.
